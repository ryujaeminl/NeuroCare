# Android install files

Install the APK that matches the device owner:

- `neurocare-patient-v2.20.apk` — patient app (`com.neurocare.app.patient`)
- `neurocare-guardian-v2.20.apk` — guardian app (`com.neurocare.app.guardian`)

Both APKs are debug-signed so they can be installed directly for testing. Android may require enabling installation from the source used to download the file. The guardian app opens the guardian dashboard; the patient app opens the conversation dashboard.
